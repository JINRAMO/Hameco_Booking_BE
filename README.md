# Hameco_Booking_BE
### 프로젝트 소개 
이 프로젝트는 미용 업계를 위한 예약 및 리뷰 관리에 대한 프로젝트입니다. 사용자는 매장을 선택해 원하는 디자이너를 선택하고, 원하는 시술을 예약하며, 시술 후 리뷰를 남길 수 있습니다. 디자이너는 자신의 예약을 관리하고, 가능 시간을 설정하며, 리뷰를 확인할 수 있고 점장은 매장을 관리 할 수 있습니다.

### 주요 기능
#### 회원가입/로그인 기능
- 사용자가 이메일 인증을 한 다음 정보를 기입하여 계정을 생성합니다.
- 회원 정보 조회, 수정 기능을 제공합니다.
- 생성한 계정으로 로그인을 할 수 있습니다.

#### 유저 기능
- 리뷰를 작성 할 수 있으며 리뷰 목록을 조회,수정,삭제 할 수 있습니다.
- 디자이너 예약이 빈 시간대에 예약을 할 수 있으며 예약의 승인 여부와 예약 목록을 조회 할 수 있습니다.

#### 점장 기능
- 파트너를 등록할수 있으며 조회,삭제 할 수 있습니다.
- 매장을 등록하고 정보를 수정 할 수 있습니다.
- 매장을 삭제 할 수 있습니다.

#### 디자이너 기능
- 예약 가능 시간을 설정 및 수정 할 수 있습니다.
- 새로운 시슬을 등록 할 수 있으며 시술 목록을 조회,삭제 할 수 있습니다.
- 자신한테 들어온 예약을 승인/거절 할 수 있습니다.
- 자신의 예약 내역을 조회 할 수 있습니다.
